# Statistical Protocol v1

## Primary

The confirmatory statistic is Delta_primary(k_primary,B), comparing only left_deep and canonical_balanced.

## Diagnostic

D_diag uses Pi_diag and includes right_deep, but it is not a headline confirmatory effect.

## Seed Null

D_seed_pair^95 and D_seed_range^95 preserve the same R-run averaging structure as the real statistic. They are diagnostic quantities only and do not trigger GO or NO-GO.

## Power

Power uses independent episode counts and empirical evidence-layout strata. It must not use effective_n = fraction_multiple_leaves x n. If power is below 0.80, a null result is inconclusive.

## NO-GO

Formal NO-GO requires a signal-bearing budget, sufficient formal power, primary and stress operators below delta_decision, CI/equivalence excluding delta_decision, qualified judge, non-ceiling-only budget, and separate online-balanced Gate handling.
